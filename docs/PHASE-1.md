# 1단계: 계층형 런타임으로 파티 6인을 기존처럼 움직이기

## 목표
tintin 없이, Anima 런타임 하나로 mud-agents 의 파티 6인이 지금과 같은 수준으로 사냥한다 (D8).
기존 tintin 스크립트는 **무엇을 하는가**의 명세다 (D15). tell 신호, 상태 변수, tick 우선순위 같은 **어떻게**는 옮기지 않고,
그 스크립트가 하려던 행동을 Anima 구조(반사 / 행동 선택 / 작업 / 파티, D13·D14)로 다시 구현한다.
LLM 은 이번 단계에 실제로 부르지 않는다. 다만 LLM 이 붙을 자리(요청·답 이벤트, 대기열, 가짜 공급자)는 만든다 (D16).
`brain/*.tin` 의 현재 값은 정적 정책값으로 가져온다.

## 구조
```
 Animus (LLM)    느린 감각기관: 비동기 질문 → 답 이벤트 (1단계는 가짜·재생 공급자)
 파티 계층       블랙보드 + 역할 배정 + 파티 목표 (거점, 순환, 집결, 휴식 동기화)
 행동 선택       지금 무엇을 할지 고름 (유틸리티 AI 또는 행동 트리, M5 에서 결정)
 작업(시퀀서)    여러 단계 절차 실행, 반사가 끼어들면 멈췄다 이어감
 반사            즉시 끼어들기 (도주, 위험 회피, 깨기)
 Memoria / 이벤트 버스 / 어댑터
```

## 명세로 제공되는 파일 (`../mud-agents/`)
- `common/login.tin` 로그인/재접속/사망 후 재입장
- `common/body.tin` 전투·휴식·도주·사냥·루팅·목표 실행
- `common/nav.tin` 방 인식, 지도, 미탐험 우선 배회, 길찾기, 어둠 탈출, 위험 출구
- `common/party*.tin` 명단과 역할, 집결지, 리더 대기 (tell 신호 체계는 옮기지 않는다, D14)
- `common/train.tin` 길드 경로와 연습
- `common/warrior.tin` `mage.tin` `cleric.tin` `thief.tin` 직업별 전투·지원 행동
- `agents/*.tin` 캐릭터별 구성, `brain/*.tin` 정책값, `maps/world.map` 지도, `logs/*.log` 실제 플레이 기록
정리본: `docs/SPEC-from-tintin.md`.

같은 워크스페이스의 tbaMUD 소스와 tintin++ 소스도 자유롭게 참고한다 (CLAUDE.md 의 "워크스페이스" 항목).
특히 어댑터의 메시지 패턴은 tbaMUD 소스에서 실제 문자열을 찾아 만들고, `lib/world/` 데이터로 Memoria 초기값을 채운다.

## 재현할 행동 (최소)
- 6인 로그인, 그룹 결성과 합류, 따라가기, 흩어지면 다시 모이기
- 리더 주도 사냥, 경비 있는 방 회피, autoassist 로 전원 참전, 도적 기습 개시
- 전사 kick/bash/rescue, 마법사 공격 주문, 성직자 치료·armor·음식/물 보급
- 휴식 동기화(리더 대기), 도주(서버 wimpy 포함), 사망 후 복귀와 시체 회수
- 길드 연습 다녀오기, 지도 작성과 배회, 어둠·위험 출구 처리
- 루팅: autoloot/autogold/autosplit, 파티원 시체에서 나온 물건은 주인에게 돌려주기

## 만들 것 (마일스톤)
- **M0** 뼈대, 결정 기록, `docs/SPEC-from-tintin.md`
- **M1** `docs/PROTOCOL.md` 이벤트 프로토콜 v0. 코드보다 먼저 쓰고 사용자 확인.
  게임 이벤트(tell 은 `comm.tell` 까지만, 파티 약속어 없음 D10), 명령과 출처(D11), LLM 요청·답(D16).
- **M2** 텍스트 어댑터 (tbaMUD) + 재생 테스트: `logs/*.log` 를 흘려 이벤트가 맞게 나오는지 검증 (명령 비교는 하지 않음, D9)
- **M3** 이벤트 버스 + JSONL 녹화 (이벤트, 명령과 출처, 계층 결정, LLM 요청·답)
- **M4** Memoria v0: 방 그래프, 위치 추적, 길찾기, 위험 출구, 몹/지역 지식
- **M5** Sigil v0 와 행동 계층: 행동 선택 방식과 Sigil 형식은 비교안을 보고 사용자가 고른다.
  반사·행동 선택·시퀀서·명령 큐, Animus 자리(가짜·재생 공급자), 검증기, `docs/SIGIL-API.md`, 패키지 겹쳐 쌓기 (D12)
- **M6** 세션 관리(한 프로세스 다중 접속, `run.sh` 대체 CLI) + Vallen 1인 실서버
- **M7** 6인 파티: 블랙보드, 역할 배정, 파티 목표 (tell 없이, D14)
- **M8** 실서버 1시간 검증과 tintin 기준선 비교

## 범위 밖
실제 LLM 호출(2단계), 허브, 웹, MCP, 빙의, GMCP/MSDP, 한글화, tbaMUD 소스 수정, 새 엔진, 외부 에이전트와의 파티 채널.

## 완료 조건
- 프로토콜 문서가 사용자 확인을 받았다
- 재생 테스트에서 방/전투/사망/프롬프트/tell 이 정확히 이벤트로 바뀐다
- 실서버에서 6인이 1시간 동안 사람 개입 없이 함께 사냥하고, 흩어지거나 죽어도 다시 모여 사냥을 이어간다
- 같은 상황에서 기존 tintin 파티보다 사망·이탈이 많지 않다
- Sigil 을 잘못 쓰면 저장 단계에서 거부되고 이전 것이 유지된다
- 엔진(`anima/`)에 캐릭터명·직업명·파티 약속어가 없고, 새 캐릭터를 패키지 조합만으로 추가할 수 있다
- 가짜 LLM 공급자로 질문 → 답 이벤트 → 재평가, 시간 초과 시 기본값, 녹화된 답 재생이 동작하고, 반사·행동 선택은 LLM 을 기다리지 않는다
- tintin 유산이 없다: 우회 코드, tell 기반 협동, 단일 tick if 사다리

## 진행 방식
- 작업 시작 전 이 문서와 `DECISIONS.md` 를 읽는다
- 순서: 프로토콜 → 어댑터+재생 테스트 → 1인(Vallen) → 6인
- 큰 결정(라이브러리, Sigil 형식, 행동 선택 방식, 디렉토리 구조)은 제안 후 사용자 확인
- 결정이 나면 `DECISIONS.md` 에 한 항목씩 추가
